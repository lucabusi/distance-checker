🔑 CARTO Basemaps API Key

Serve per lo sfondo delle mappe Leaflet (percorsi OSRM e zona ottimale). La key è gratuita, non richiede account: richiedila su carto.com/basemaps · La key viene salvata solo localmente nel browser.
Senza key le mappe usano le tile standard di OpenStreetMap, che possono non caricarsi aprendo la pagina da file://: in quel caso servi la pagina da un web server locale.

🔑 Google Maps API Key

Serve una key con Maps JavaScript API, Geocoding API, Distance Matrix API e Directions API abilitate.
Ottienila su Google Cloud Console · La key viene salvata solo localmente nel browser.
⚠ Per usare Maps JS API nel browser, assicurati di aver autorizzato il dominio (o localhost / file://) nelle restrizioni HTTP della key.
